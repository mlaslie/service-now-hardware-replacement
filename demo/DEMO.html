Before you start

once

  1. Clear old demo tickets (keeps users and equipment)

    cd ~/ADK/hardware_replacement && uv run --group seed python seed/sn_seed.py clear-tickets --yes

    If the users or equipment were reset, seed them again first:

    cd ~/ADK/hardware_replacement && uv run --group seed python seed/sn_seed.py set seed/users.example.json

  2. Optional handout: the asset register PDF

    cd ~/ADK/hardware_replacement && uv run --group seed python seed/sn_seed.py report && open seed/state/office-assets.pdf

  3. Jane has a ServiceNow password

    As admin: jane.doe's user record, then Set Password, untick Password needs reset, and click Update.

  4. One browser profile per person, each authorized as that person

    Jane Gemini Enterprise mobile app (or a browser) as jane.doe@example.com. John Gemini Enterprise in a desktop browser as john.doe@example.com. On first use each authorizes ServiceNow as jane.doe / john.doe. Never authorize while that browser is signed in to ServiceNow as admin.

  5. Photos where the phone or desktop can attach them

    Clinical Engineering stickers and laptop photos. In a Mac file dialog, ⌘⇧G takes a pasted path.

    ~/ADK/hardware_replacement/demo/tag-pump.jpg
    ~/ADK/hardware_replacement/demo/tag-mri.jpg
    ~/ADK/hardware_replacement/demo/cracked.jpg

  6. Service desk tab open (admin, third browser profile)

    Hardware tickets, newest first

Start every scene in a new conversation. The agent first asks "Are you on the Gemini Enterprise Desktop or Mobile App?": answer 1 on the phone, 2 on desktop.

Opening

30 sec
In a hospital, the person who notices a broken MRI or a cracked infusion pump is a technologist or a nurse in the middle of a shift. Today they phone the service desk or fill in a form that asks for an asset tag and a team they don't know. This agent takes a sentence or a photo. It already knows who they are, because Gemini Enterprise passes their identity through to ServiceNow.

Jane never typed a tag, a form field or a team name. The agent found the MRI from "room 104", asked him to check it against the sticker, and routed it to Imaging Engineering at the right room. On his phone it's plain text with numbered choices; on a desktop the same steps are buttons.

Shared equipment gets reported by everyone who walks past it. Instead of five duplicate tickets, the second person adds what they saw to the first one and gets the same updates.

Close

20 sec
One agent for laptops and MRIs, on the phone or the desktop. It knows who you are and finds the equipment from how you describe it. The right team gets it with the location, duplicates become followers, and "any update?" always gets a live answer.
